# 저장된 템플릿 사용

`base.pptx`에는 아래 8가지 모양이 들어 있습니다. `base.pdf`와 `previews/`에서 모양을 확인하고, 필요한 슬라이드를 복제해 사용하세요. 모든 모양을 한 발표에서 사용해야 하는 것은 아닙니다.

| 번호 | 파일 | 모양 |
|---|---|---|
| 01 | `layouts/01_cover.pptx` | 파란 표지, 제목·부제·작성자 |
| 02 | `layouts/02_contents.pptx` | 목차 |
| 03 | `layouts/03_section.pptx` | 섹션 구분 |
| 04 | `layouts/04_body.pptx` | 제목과 전체 너비 본문 상자 |
| 05 | `layouts/05_image_text.pptx` | 왼쪽 이미지, 오른쪽 설명 |
| 06 | `layouts/06_code_text.pptx` | 왼쪽 코드, 오른쪽 설명 |
| 07 | `layouts/07_table_text.pptx` | 위쪽 편집 가능한 표, 아래 설명 |
| 08 | `layouts/08_two_images.pptx` | 이미지 두 개와 아래 설명 |

이 목록은 사용할 수 있는 모양의 예시다. 사진 수나 발표 순서를 고정하는 규칙이 아니다. 이미지 자리표시자는 이미지로 교체하고, 설명용 예문과 사용하지 않는 객체는 삭제한다. 슬라이드 번호는 최종 순서에 맞게 갱신한다.

CBNU 표시는 편집 가능한 텍스트다. 디자인 수치는 `style.json`에서 필요한 항목만 확인한다.

사용자가 제공한 디자인을 기반으로 편집 가능한 기존 PPT에서 모양을 추출했다. 원본 과제의 내용·수치·그림·코드는 템플릿에서 제거했다. 추출된 이 파일들의 모양이 앞으로의 디자인 기준이며, 원본 PDF의 특정 페이지를 다시 가져올 필요는 없다.
