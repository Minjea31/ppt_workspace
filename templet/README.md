# 공통 발표 템플릿

사용자 지정 week4 PDF의 **디자인만** 재구성한 16:9 템플릿입니다. week4의 과제 내용은 포함하지 않습니다.

- 전체 폭 파란 제목 띠(높이 61.5pt), 가장자리 쪽수와 CBNU 로고.
- 글꼴: **Pretendard Bold**. 텍스트·표·배경·설명 패널은 편집 가능합니다.
- 고정 1.2cm 여백 없음. 레이아웃의 기존 bbox 안에 내용을 작성합니다.
- 모든 설명 박스: 흰색 내부를 파란 외곽에서 좌우·하단 12pt 띄웁니다. 제목 없는 박스는 상단도 12pt, 제목 있는 박스는 제목 띠 40.5pt를 유지합니다.
- 텍스트 bbox는 흰색 내부에서 다시 12pt 안쪽에 배치합니다. 둥근 모서리에 흰색 내부가 닿지 않습니다.
- 이미지+설명은 week4의 420pt 이미지 영역과 450pt 설명 패널 배치를 사용합니다.
- 표+설명은 week4의 3열 6행 표와 아래 설명 패널을 사용합니다.
- `base.pptx`, `base.pdf`, `layouts/`, `previews/`는 같은 디자인입니다.
- 글꼴 파일과 라이선스: `fonts/Pretendard-Bold.ttf`, `fonts/LICENSE.txt`.

|모양|용도|
|---|---|
|01_cover|표지|
|02_contents|목차|
|03_section|섹션 구분|
|04_body|전체 폭 설명·수식|
|05_image_text|이미지와 오른쪽 설명|
|06_code_text|코드와 오른쪽 설명|
|07_table_text|3열 6행 표와 아래 설명|
|08_two_images|이미지 두 개 비교|
|09_equation|편집 가능한 한 줄 수식과 설명|
|10_four_images|이미지 네 개와 비교 결과|

사용하지 않는 자리표시자는 제거하고, 내용이 길면 슬라이드를 나눕니다.
